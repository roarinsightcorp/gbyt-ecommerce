# G by T Global Trading Ventures

Production-grade commercial e-commerce platform.

## Architecture

- Frontend: Next.js + TypeScript
- Backend: Django + Django REST Framework
- Database: MySQL
- Cache/Tasks: Redis + Celery
- Payments: Paystack
- Object Storage: Cloudflare R2
- CDN/WAF: Cloudflare

## Project Structure

- `frontend/` — Next.js storefront and administration interface
- `backend/` — Django REST API
- `docs/` — technical and project documentation
